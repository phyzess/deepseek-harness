# @deepseek-ai/dsh-client-ui-settings-plugin-inventory

[English](README.md) | 中文

Web 设置中的只读**插件列表**标签页。浏览器插件注册一个 id 为 `all` 的本地化 `settings.plugins.tab` 贡献；“插件”分区拥有导航入口与标签栏。插件激活期间不会读取 Remote；首次选择该标签页时才挂载组件，并通过 [`api-remotes`](../../api/remotes/README.md) 懒调用 `ctx.remote.pluginInventory.list()`。

该标签页按挂载平面分组渲染可搜索清单——宿主插件、Agent 预设与运行时动态挂载，每个分区以本地化名称与计数为标题。每张卡片以**完整模块名**为标题，下方直接展示 Loader 树条目 id，并附有效启停状态标签；已启用的条目还会以彩色圆点表示根 fiber 状态；卡片的展开交互仍然可以查看有效配置状态与 Cordis 状态。同一模块被挂载多次时，每张卡片都会带 `×N` 多重挂载角标，因此发货 Web 组合中的同名重复——同一插件既作为有意停用的宿主行、又作为常驻 Agent 预设行挂载——始终可以区分。条目 id 既是 React key，也是始终可见的身份值与额外的搜索目标；平面分组只是对 id 形状的展示层分类，不改变其身份语义。加载、空结果、无匹配结果与通用失败状态只属于已挂载组件；读取失败后可以重试，且不会暴露传输细节。注册使用 `ctx.slots.inject()`，因此能跟随标签 slot 的延迟声明、重新声明、本地化变化与 teardown，而无需 import 分区拥有方。

## 模型体验

无，因为本包只在浏览器设置中展示 Host 拥有的部署快照，不注册任何模型接口。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **每次 Settings 挂载或重试只读取一份快照** —— 标签页不订阅 Loader 变化，也不会在重连后自动重新读取；切换标签页会保留当前快照，重新打开 Settings 则会取得新快照。
- **只读 Loader 视图** —— 本地搜索不会额外引入来源、当前浏览器激活诊断或插件修改控件。
- **平面分组基于 id 形状** —— 宿主/预设/运行时分组来自条目 id 的 `include:`/`agent-presets` 片段，而非 Host 提供的平面字段；若某个组合以不同形状的 id 铸造条目，需要同步更新分类器。
